# InsightFlow

Веб-приложение для автоматической визуализации и анализа бизнес-данных. Интерфейс позволяет загрузить CSV, Excel или JSON-файл, автоматически определить тип данных (продажи, маркетинг, финансы), построить соответствующие графики и получить инсайты и приоритизированные рекомендации.

## Как запустить

1. Откройте файл `index.html` в современном браузере (Chrome, Edge, Firefox, Safari).
2. Перетащите файл с данными в область загрузки или выберите его вручную.
3. Дождитесь обработки и исследуйте:
   - предпросмотр и классификацию датасета;
   - список рекомендованных метрик с возможностью отображения на графиках;
   - визуализации (круговые диаграммы, линейные графики, бар-чарты, дашборды);
   - автоматически сформированные инсайты и рекомендации.

## Поддерживаемые форматы и ограничения

- CSV (`.csv`, `.txt`), Excel (`.xlsx`, `.xls`), JSON (`.json`).
- Максимальный размер файла — 5 МБ.
- Данные обрабатываются только в браузере и не передаются на сервер.

## Используемые библиотеки

- [Papa Parse](https://www.papaparse.com/) — парсинг CSV.
- [SheetJS](https://sheetjs.com/) — чтение Excel.
- [Plotly](https://plotly.com/javascript/) — построение графиков.

## Структура проекта

- `index.html` — основной интерфейс и логика приложения.
- `TECH_SPEC.md` — исходная техническая спецификация.
